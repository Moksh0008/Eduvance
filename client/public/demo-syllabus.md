# Computer Science - Semester 5 Syllabus

## Subject 1: Database Management Systems (DBMS)

### Unit 1: ER Model
- Entity-Relationship Model
- Entities, Attributes, and Relationships
- ER Diagram Notation
- Cardinality and Participation Constraints
- Weak Entities
- Aggregation

### Unit 2: Relational Model
- Relational Data Model
- Relational Algebra
- SQL Fundamentals
- DDL, DML, DCL Commands
- Joins and Subqueries
- Views and Indexes

### Unit 3: Normalization
- Functional Dependencies
- Normal Forms (1NF, 2NF, 3NF, BCNF)
- Decomposition Methods
- Lossless Join Decomposition
- Dependency Preservation

### Unit 4: Transaction Management
- ACID Properties
- Serializability
- Conflict Serializability
- Two-Phase Locking
- Deadlock Detection and Prevention
- Recovery Techniques

## Subject 2: Computer Networks (CN)

### Unit 1: OSI Model
- Seven Layers of OSI
- Data Encapsulation
- Physical Layer
- Data Link Layer
- Network Layer
- Transport Layer
- Session, Presentation, Application Layers

### Unit 2: TCP/IP Model
- TCP/IP Protocol Suite
- IP Addressing (IPv4, IPv6)
- Subnetting
- ARP and RARP
- ICMP Protocol

### Unit 3: Routing Algorithms
- Distance Vector Routing
- Link State Routing
- Dijkstra's Algorithm
- Bellman-Ford Algorithm
- OSPF and RIP Protocols

### Unit 4: Congestion Control
- Congestion vs Flow Control
- TCP Congestion Control
- Slow Start and Congestion Avoidance
- Fast Retransmit and Fast Recovery
- Traffic Shaping

- Inter-Process Communication

### Unit 2: Memory Management
- Logical vs Physical Address Space
- Contiguous Memory Allocation

### Unit 3: File Systems

### Unit 4: Deadlocks
- Deadlock Conditions

### Unit 1: Complexity Analysis
- Time and Space Complexity

- Binary Search
